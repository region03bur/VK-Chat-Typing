# 🚀 VK Auto Typing 

Автоматическая отправка статуса "печатает..." в УКАЗАННЫЙ (НЕ ВО ВСЕ ЧАТЫ, ТОЛЬКО ПО АЙДИ) чат ВКонтакте с заданным интервалом. (по умолчанию 3 секунды - эффект бесконечного цикла)

## 📋 Описание

Скрипт имитирует набор текста в беседе ВКонтакте путем периодической отправки статуса "печатает...". Полезно для:
- Поддержания активности в беседе (ну и для заеба всех, будь готов, тебя точно отхуесосят😂)
- Тестирования функций VK API

## ✨ Возможности

- 🔄 Автоматическая отправка статуса "печатает..." каждые 3 секунды
- 📊 Отображение статистики в реальном времени
- 📈 Часовая статистика работы
- ⚠️ Обработка ошибок и автоматическое восстановление
- 🎨 Красивое оформление вывода в консоли
- ⏱️ Расчет времени работы и успешности операций

## ⚙️ Настройка

### Получение VK токена
1. Перейдите на https://vkhost.github.io/
2. Выбрать VK Admin, далее скопировать токен от token= до знака &, как на изображении ![вот здесь](https://github.com/region03bur/VK-Chat-Typing/blob/main/token.jpg)


### Параметры в коде
Откройте файл `autotypingchat.py` и измените следующие параметры:

```python
VK_TOKEN = 'ваш_токен_здесь'  # Ваш VK токен начинается с vk1.a.Rkd-i7f6a7Nmt
CHAT_ID = 79                   # ID беседы без 20000000, только последние 3 или 2 цифры, в моем случае айди 113, у кого как, изображение будет внизу 👇
INTERVAL = 3                    # Интервал отправки (секунд)
```
![вот как тут](https://github.com/region03bur/VK-Chat-Typing/blob/main/chat_id.jpg)

## 🚀 Использование

Запустите скрипт:
```bash
python autotypingchat.py
```

### Управление
- `Ctrl+C` - остановка скрипта и показ финальной статистики

## 📊 Статистика

Скрипт показывает:
- **Общая статистика** - при запуске и каждый час
- **Финальная статистика** - при завершении работы

Включает:
- Время работы
- Количество отправленных статусов
- Количество ошибок
- Процент успешных операций
- Общее количество операций

## 🔧 Конфигурация

Доступные для изменения параметры:
- `INTERVAL` - интервал отправки (по умолчанию 3 сек)
- `max_fails` - количество ошибок до паузы (5), при нестабильной сети разумеется будут ошибки типа: "HTTPSConnectionPool(host='api.vk.com', port=443): Read timed out. (read timeout=5)" это не страшно для работы скрипта, со стабильной сетью все будет в порядке
- `fail_sleep` - длительность паузы при ошибках (30 сек)

## ⚠️ Важно

- Скрипт использует официальный VK API
- Не нарушайте правила использования VK API
- Рекомендуемый интервал отправки - не менее 3 секунд

## 📝 Требования

- Python 3.6+, в принципе во всех версиях должно работать
- requests библиотека
- Активный VK токен
